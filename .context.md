# OpenERP - Contexto do Projeto

## Estrutura do Projeto
- Backend: Go 1.21+
- Banco de Dados: MySQL 8.0 (etools_openerp)
- ORM: GORM
- Framework Web: Gin
- Autenticação: JWT

## Architecture
- Repository Pattern: repository/
- Service Layer: service/
- Handlers: handler/
- DTOs: dto/
- Utils: utils/
- Constants: constants/

## Autenticação JWT
- Login: POST /api/v1/auth/login
- Refresh: POST /api/v1/auth/refresh
- Me: GET /api/v1/auth/me
- Logout: POST /api/v1/auth/logout

## Padrões de Código
- Constantes centralizadas em constants/constants.go
- Campos de auditoria: CreatedAt, UpdatedAt, DeletedAt, CreatedBy, UpdatedBy
- Soft delete: método SoftDelete()
- Hooks GORM: BeforeCreate, BeforeUpdate (com *gorm.DB)
- Relacionamentos: usar foreignKey e references
